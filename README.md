# 💰 SoftGrowTech_Expense_Tracker

A simple command-line based Expense Tracker application built using Python. This project helps users manage their daily expenses by adding, viewing, searching, deleting, and summarizing expenses using file handling (JSON).

## 🚀 Features
- Add new expenses  
- View all expenses  
- Search expenses by title  
- Delete expenses  
- Show total summary  
- Category-wise spending analysis  
- Data stored in JSON file (persistent storage)  
- Timestamp for each expense  

## 🛠️ Technologies Used
Python 3, File Handling (JSON), DateTime Module, Command Line Interface (CLI)

## ▶️ How to Run
1. Clone the repository  
2. Open terminal in project folder  
3. Run command:  
   python main.py
